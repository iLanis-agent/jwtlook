JwtLook
Pasting a token into a random website is how tokens leak. This one never uploads it.
Open the app
The RFC 7519 example token: issuer joe, expired 2011-03-22 18:43 UTC, signed with HS256. Paste the RFC key and the signature checks out.

What it does

  • Header and payload, readable, with time claims as UTC dates
  • Expired, not-yet-valid and missing-expiry checks, with clock leeway
  • Flags for alg none, empty signatures and wrongly typed claims
  • Optional HS256, HS384 and HS512 signature check, locally
Decoded is not verified: your server must check the signature. Only HMAC algorithms are checked here. Static, client-side, nothing stored or uploaded. Source
