JwtLook

Paste a JSON Web Token. Read it, check its dates and optionally check its HMAC signature. Nothing leaves this page.
Decoded is not verified. Anyone can write a JWT with any claims. Only a signature check with the right key tells you the token is genuine, and your server must do that, not this page. Format per RFC 7519 (JWT) and RFC 7515 (JWS): three base64url parts, header, payload and signature. "exp", "nbf" and "iat" are seconds since 1970 (NumericDate); "exp" is the first instant the token must be rejected, and RFC 7519 allows a small leeway for clock skew. The first sample is the RFC 7519 section 3.1 token, its secret is the RFC 7515 appendix A.1 key (base64url) so you can see a valid signature: pick "base64url" and paste AyM1SysPpbyDfgZld3umj1qzKObwVMkoqQ-EstJQLr_T-1qS0gZH75aKtMN3Yj0iPS4hcgUuTwjAzZr1Z9CAow. This page checks HMAC algorithms only; RS256, ES256 and others need a public key and are not checked. Encrypted tokens (5 parts) cannot be read. Do not paste live production secrets into any website you do not trust: this page runs offline in your browser and stores nothing, but the habit is worth keeping.
